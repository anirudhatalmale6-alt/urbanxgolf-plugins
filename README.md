# urbanXgolf – WordPress-Plugins

Drei kleine Plugins für urbanxgolf.de. Jedes lässt sich unter *Plugins* einzeln aktivieren und mit einem Klick wieder deaktivieren.

| Datei | Plugin | Was es tut |
|---|---|---|
| [ug-bildschutz.zip](https://github.com/anirudhatalmale6-alt/urbanxgolf-plugins/raw/main/ug-bildschutz.zip) | urbanXgolf — Bildschutz | Rechtsklick, Ziehen und Halte-Menü auf Fotos abgeschaltet; Fotos höchstens 1536 px breit |
| [ug-fusszeile.zip](https://github.com/anirudhatalmale6-alt/urbanxgolf-plugins/raw/main/ug-fusszeile.zip) | urbanXgolf — Signatur in der Fußzeile (1.2) | Dezente Zeile unter der Spalte „Schnellzugriff“ — nach dem Ersetzen in Elementor unter *Werkzeuge* einmal *Clear Files & Data* (Dateien und Daten löschen) klicken |
| [ug-format.zip](https://github.com/anirudhatalmale6-alt/urbanxgolf-plugins/raw/main/ug-format.zip) | urbanXgolf — Layout (1.9) | Fotos in 3:2 (Parcours-Kacheln, Bilderraster, CSS-Klasse `ug-32`); Copyright zweizeilig, klein und linksbündig unter dem Logo (auch wenn es in Elementor woanders steht), auf einer Höhe mit der Signatur; lesbares Handy-Menü; Adresszeile im Footer sauber umbrochen; „Über uns“: Bilderraster wächst symmetrisch mit, Fotos unter „Unterwegs“ 4:3 mit weißem Rahmen; Foto auf „Kontakt“ beginnt auf Höhe der Überschrift; Sprachauswahl DE/EN ausblendbar (Einstellungen › Allgemein); Fotoreihen auf „Spielen“ und „Über uns“ per Klick vergrößerbar |

## Installieren
1. ZIP-Datei herunterladen (nicht entpacken)
2. WordPress: *Plugins → Neues Plugin hinzufügen → Plugin hochladen*
3. Datei auswählen → *Jetzt installieren* → *Plugin aktivieren*

Der Quelltext liegt im Ordner `src/`.
